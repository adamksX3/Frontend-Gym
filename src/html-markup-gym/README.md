# Исходники HTML Markup Gym

Из этих файлов собирается `Тренажёры/html-markup-gym.html` (около 110 КБ). Править задачи нужно здесь, а не в готовом HTML. Устроен так же, как [[Тренажёр CSS Layout Gym]] (`../css-layout-gym/`).

| Файл | Что это |
| --- | --- |
| `src/tasks.js` | все задачи: текст, пример на другом коде, подсказка, заготовка HTML, решение и проверки |
| `src/engine.js` | проверка: разметка превращается в настоящий DOM в iframe, проверки выполняются внутри него и возвращаются через `postMessage`; подсчёт парных тегов и поиск несуществующих |
| `src/app.js` | интерфейс: список задач, редактор, живой предпросмотр, прогресс в `localStorage` (ключ `htmlgym-v1`) |
| `src/page.html` | разметка и стили, места для вставки помечены `__ИМЕНЕМ__` |
| `build.js` | склеивает всё в `dist/index.html` |
| `e2e.py` | прогон в настоящем Chrome (Playwright): каждое решение проходит, каждая заготовка не проходит |

## Как устроена проверка

Задача = текст + HTML Артура. Обычно его разметка попадает в `<body>`; у задач с флагом `doc: true` он пишет страницу целиком (`<!DOCTYPE>`, `html`, `head`). В проверках доступны: `c.q c.qa c.$ c.$$ c.txt c.tag c.want c.before c.chain c.doc`; проверка возвращает `true` или текст ошибки. Служебный скрипт перед проверкой удаляется из DOM, чтобы не попасть в `textContent`.

## Сборка и проверка

```bash
node build.js          # dist/index.html
python3 e2e.py         # solutions failing: [] | starters passing: []
```

## После правок

1. `python3 e2e.py` → оба списка пустые.
2. Опубликовать новую версию артефакта и заменить `Тренажёры/html-markup-gym.html`.
3. Если менялся список задач — обновить чек-лист в `Тренажёр HTML Markup Gym.md`.

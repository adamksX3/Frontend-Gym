# Исходники Frontend Gym (общая оболочка)

Из этих файлов собирается `Тренажёры/frontend-gym.html` (около 7 МБ): один файл с вкладками, внутри которого целиком лежат готовые тренажёры. См. [[Тренажёр Frontend Gym]].

| Файл | Что это |
| --- | --- |
| `src/hub.html` | разметка и стили шапки; `__GYM_DATA__` и `__HUB_JS__` — места для вставки |
| `src/hub.js` | вкладки, общий счётчик, перенос прогресса (текстом и файлом) |
| `build.js` | берёт готовые файлы тренажёров из папки `gyms/` и вкладывает их в оболочку |
| `totals.json` | число задач в каждом тренажёре (для счётчиков на вкладках) |
| `e2e.py` | прогон в Chrome: каждая вкладка открывается и решает задачу, счётчики растут, прогресс переживает перезагрузку, перенос работает |

## Как это устроено

- Каждый тренажёр хранится в оболочке как JSON-строка в `<script type="application/json">` и при первом открытии вкладки загружается в свой `iframe` через `srcdoc`. Сами тренажёры не изменены.
- Прогресс тренажёры пишут в `localStorage` под прежними ключами (`jsgym-v1`, `tsgym-v1`, `htmlgym-v1`, `cssgym-v1`, `reactgym-v1`, `toolsgym-v1`). Оболочка читает те же ключи для счётчиков.
- Единственная добавка: в начало каждого тренажёра вставляется маленький скрипт, который гасит ошибку `history.replaceState` (внутри `srcdoc` у страницы нет своего адреса).

## Сборка

Из корня репозитория: `node build.js`. Скрипт собирает каждый тренажёр, кладёт готовые файлы в `src/hub/gyms/`, запускает `src/hub/build.js` и копирует результат в `frontend-gym.html`.

## Как добавить новый тренажёр

1. Собрать его отдельным файлом (как `../react-gym/`), ключ прогресса вида `имяgym-v1`.
2. Добавить строку в массив `GYMS` в `src/hub/build.js` и в корневом `build.js`, число задач — в `totals.json`.
3. Если его название стояло в массиве `SOON` в `src/hub.js` (пометка «скоро»), убрать его оттуда.
4. `node build.js`, `python3 e2e.py`, заменить `Тренажёры/frontend-gym.html`, опубликовать новую версию артефакта.

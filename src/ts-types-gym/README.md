# Исходники TS Types Gym

Из этих файлов собирается `Тренажёры/ts-types-gym.html`. Править задачи нужно здесь, а не в готовом HTML (он весит 4,5 МБ: внутри компилятор).

| Файл | Что это |
| --- | --- |
| `src/tasks.js` | все задачи: текст, пример, подсказка, заготовка, решение, проверки типов и тесты |
| `src/engine.js` | проверка: компиляция, правила (`any`, `as`, тип результата), проверки типов, запуск |
| `src/app.js` | интерфейс: список задач, редактор, вывод результатов, прогресс в `localStorage` (ключ `tsgym-v1`) |
| `src/page.html` | разметка и стили, места для вставки помечены `__ИМЕНЕМ__` |
| `vendor/` | сжатый компилятор TypeScript 6.0 (`ts.min.js`) и его lib-файлы (`libs.json`); уже лежат в репозитории |
| `prepare.js` | заново создаёт `vendor/` из пакета `typescript` (нужно только при смене версии компилятора) |
| `build.js` | склеивает всё в `dist/index.html` |
| `selftest.js` | каждое решение проходит, каждая заготовка не проходит, каждый пример компилируется |
| `e2e.py` | то же в настоящем браузере (Playwright + Chrome) |

## Сборка

```bash
node selftest.js    # должно быть problems: 0
node build.js       # dist/index.html
```

Обновить компилятор: `npm install --no-save typescript@~6.0.0 esbuild`, потом `node prepare.js`.

Версия TypeScript — 6.0.x: в 7.x компилятор переписан и в браузер так не встраивается.

## После правок

1. `node selftest.js` → 0 проблем.
2. `node build.js`, открыть `dist/index.html`, проверить изменённую задачу.
3. Опубликовать новую версию артефакта и заменить `Тренажёры/ts-types-gym.html`.
4. Если менялся список задач — обновить чек-лист в `Тренажёр TS Types Gym.md`.

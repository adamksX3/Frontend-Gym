# Исходники CSS Layout Gym

Из этих файлов собирается `Тренажёры/css-layout-gym.html` (около 140 КБ). Править задачи нужно здесь, а не в готовом HTML.

| Файл | Что это |
| --- | --- |
| `src/tasks.js` | все задачи: текст, пример на другом коде, подсказка, заготовка CSS, решение и проверки |
| `src/engine.js` | проверка: строит страницу в iframe, проверки выполняются внутри него и возвращаются через `postMessage`; разбор опечаток в свойствах |
| `src/app.js` | интерфейс: список задач, редактор, живой предпросмотр, прогресс в `localStorage` (ключ `cssgym-v1`) |
| `src/page.html` | разметка и стили, места для вставки помечены `__ИМЕНЕМ__` |
| `build.js` | склеивает всё в `dist/index.html` |
| `e2e.py` | прогон в настоящем Chrome (Playwright): каждое решение проходит, каждая заготовка не проходит |

## Как устроена проверка

Задача = готовый HTML + CSS Артура. Страница строится в скрытом iframe нужной ширины (`check.w`, для адаптива), внутри читаются `getComputedStyle` и `getBoundingClientRect`. Родитель чужой документ не читает: в «песочнице» артефакта это запрещено, поэтому результат приходит сообщением. `:hover` эмулируется копированием правил под служебный класс. В проверках доступны: `c.$ c.$$ c.cs c.px c.box c.near c.want c.rgb c.rules c.hover c.attr c.css`.

## Сборка и проверка

```bash
node build.js          # dist/index.html
python3 e2e.py         # solutions failing: [] | starters passing: []
```

Нужны Node и Playwright с Chrome.

## После правок

1. `python3 e2e.py` → оба списка пустые.
2. Опубликовать новую версию артефакта и заменить `Тренажёры/css-layout-gym.html`.
3. Если менялся список задач — обновить чек-лист в `Тренажёр CSS Layout Gym.md`.

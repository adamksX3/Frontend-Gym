# Frontend Gym

Тренажёр по курсу фронтенда: 372 задачи с автоматической проверкой. Один файл `frontend-gym.html`, работает без интернета и без установки.

| Вкладка | Задач | Что внутри | Как проверяется |
| --- | --- | --- | --- |
| JavaScript | 72 | методы строк, массивов и объектов | функция запускается на тестах |
| TypeScript | 66 | типы, объекты, сужение, дженерики | настоящий компилятор TypeScript 6.0 |
| HTML | 49 | структура, ссылки, семантика, формы, таблицы, доступность | разметка превращается в DOM, проверки — запросы к нему |
| CSS | 65 | селекторы, блочная модель, текст, Flexbox, Grid, адаптив | вычисленные стили и размеры элементов |
| React | 54 | JSX, пропсы, списки, состояние, формы, эффекты, композиция | компонент работает в настоящем React 18, тренажёр сам кликает и печатает |
| Git и инструменты | 66 | Git, GitHub, JSON, Prettier, Husky | симулятор git, `JSON.parse`, настоящий Prettier 3 |

## Как запустить

- **Windows:** двойной клик по `Frontend Gym.bat`. Тренажёр откроется отдельным окном в Chrome (если его нет — в Edge).
- **Любая система:** открыть `frontend-gym.html` в браузере. Если двойной клик открывает файл в редакторе кода, перетащи файл в окно браузера.

Сервер, Node.js и интернет для работы не нужны. Без интернета вместо шрифтов Google подставятся системные.

## Прогресс

Решённые задачи и черновики хранятся в браузере (`localStorage`), а не в этом репозитории.

- Открывай тренажёр в одном и том же браузере.
- Кнопка «Прогресс» в шапке сохраняет прогресс в файл `.json` и загружает его обратно. Так его можно перенести на другой компьютер или положить в репозиторий.
- При загрузке прогресс объединяется с текущим: решённое остаётся решённым.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `frontend-gym.html` | готовый тренажёр, все вкладки в одном файле (около 8 МБ) |
| `Frontend Gym.bat` | запуск отдельным окном на Windows |
| `build.js` | пересборка `frontend-gym.html` из исходников |
| `src/hub/` | оболочка с вкладками, общим счётчиком и переносом прогресса |
| `src/ts-types-gym/`, `src/html-markup-gym/`, `src/css-layout-gym/`, `src/react-gym/`, `src/tools-gym/` | исходники тренажёров: задачи (`src/tasks.js`), проверка (`src/engine.js`), интерфейс (`src/app.js`, `src/page.html`) |
| `src/*/vendor/` | встроенные библиотеки (см. ниже) |
| `prebuilt/js-methods-gym.html` | тренажёр JavaScript готовым файлом: раздельных исходников у него нет |

В каждой папке тренажёра есть свой `README.md` с описанием формата задач.

## Пересборка

Нужна только после правок в `src/`. Требуется Node.js, пакеты устанавливать не надо:

```bash
node build.js
```

Скрипт собирает каждый тренажёр и общий файл. Задачи правят в `src/<тренажёр>/src/tasks.js`. Если изменилось число задач, его нужно поправить в `src/hub/totals.json`.

Тренажёр JavaScript пересобрать нельзя: он вкладывается в общий файл как есть.

## Проверки

- `src/ts-types-gym/selftest.js` (`node selftest.js`): каждое решение проходит, каждая заготовка не проходит.
- Файлы `e2e.py` и `probe.py` прогоняют тренажёры в настоящем Chrome через Playwright. Они написаны под Linux (путь к Chrome `/usr/bin/google-chrome`) и на Windows без правок не запустятся.

## Ограничения

- React: один файл `App.jsx`, без TypeScript, сборщика и сети.
- Git: симулятор знает основные команды, но не все (нет `rebase`, `cherry-pick`, `tag`). npm и npx не запускаются.
- Сохранение прогресса файлом работает, когда тренажёр открыт с диска.
